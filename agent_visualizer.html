🔄 History/RAG Agent ReAct Loop — Step by Step

Reason → Act → Observe → Repeat until enough evidence is found (max 5 iterations)

❓ Question:

"Why was the authentication mechanism redesigned?"

Repo: seL4/seL4

Iteration 1 search_commits

💭 Thought

The question asks WHY auth was redesigned. I should search commit history for auth-related changes first.

⚡ Action

search_commits("auth redesign security capability")

👁 Observe

Found 3 commits — [commit:a1b2c3d4] Redesign auth to use capability-based security (conf: 0.92)

Iteration 2 search_issues

💭 Thought

Found WHAT changed but need to understand WHY. Let me check issues for the security motivation.

⚡ Action

search_issues("security vulnerability auth replay attack")

👁 Observe

Found 2 issues — [issue:142] Security audit: password auth vulnerable to replay attacks (conf: 0.87)

Iteration 3 get_linked

💭 Thought

Issue #142 explains WHY — security audit. Now let me find the PR that implemented the fix for the full picture.

⚡ Action

get_linked("issue:142")

👁 Observe

Found linked PR — [pr:89] Implement capability-based auth (fixes #142) (conf: 0.85)

Iteration 4 — FINISH

💭 Thought

I have commit (WHAT) + issue (WHY) + PR (HOW). Complete picture: security audit → vulnerability → capability redesign. Finishing.

✅ Action

finish("Security audit #142 → PR #89 → auth redesign")

📋 Result

3 evidence pieces posted to Blackboard (commit + issue + PR)

✅ ReAct Loop Complete — 4 iterations, 3 evidence pieces collected

The agent autonomously decided which tools to use and when to stop. This is the power of the ReAct pattern!
